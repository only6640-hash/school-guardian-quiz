라온창의과학 홈페이지 v1

구성
- index.html: 메인 페이지
- science.html: 초·중등과학
- invention.html: 발명대회
- fair.html: 과학전람회
- gifted.html: 영재교육원
- school.html: 내신과학
- admissions.html: 입시과학
- consulting.html: 입시상담
- about.html: 학원 소개
- achievements.html: 학생 성장 기록
- assets/: 공통 CSS, JS, 로고 및 일러스트

모바일 구성
- 상단 고정 헤더
- 왼쪽 슬라이드 전체 메뉴
- 하단 빠른 메뉴
- 메인 페이지에서 모든 교육 과정 우선 노출
- 각 과정의 더보기 버튼이 상세 서브 페이지로 연결

GitHub Pages 업로드
1. 이 폴더의 모든 파일을 저장소 루트 또는 원하는 하위 폴더에 업로드합니다.
2. GitHub Pages가 활성화되어 있다면 index.html이 시작 페이지가 됩니다.
3. 상담 연락처, 위치, 실제 수상 실적과 사진은 이후 수정합니다.
