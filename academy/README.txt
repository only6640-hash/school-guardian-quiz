구성

- science.html: 초·중등과학
- invention.html: 발명대회
- fair.html: 과학전람회
- gifted.html: 영재교육원
- school.html: 내신과학

모바일 구성
- 상단 고정 헤더
- 왼쪽 슬라이드 전체 메뉴
- 하단 빠른 메뉴
- 메인 페이지에서 모든 교육 과정 우선 노출
- 각 과정의 더보기 버튼이 상세 서브 페이지로 연결

GitHub Pages 업로드
1. 이 폴더의 모든 파일을 저장소 루트 또는 원하는 하위 폴더에 업로드합니다.
2. GitHub Pages가 활성화되어 있다면 index.html이 시작 페이지가 됩니다.
3. 상담 연락처, 위치, 실제 수상 실적과 사진은 이후 수정합니다.

v9 수상·합격 실적 페이지
- 연도·분야 선택 버튼과 필터 기능을 전부 제거
- 2026 → 2025 → 2024 순서로 모든 내용을 항상 표시
- 사용자가 제공한 수상 이미지 파일은 홈페이지에 사용하지 않음
- 이미지의 수상·합격 문구를 실제 HTML 텍스트로 입력
- 연도별 상장형 네이비·골드 디자인 적용


v10 수상실적 디자인 개선
- 수상실적 카드 전체 중앙 정렬
- 대회명, 상명, 학생명 글자 크기 확대
- 네이비·골드 계열의 상장·훈장형 디자인으로 전면 수정
- 필터 없이 2026, 2025, 2024 순서로 전체 실적 표시


v11 수상자 표시 개선
- 학생 정보를 평범한 목록이 아니라 중앙 정렬 수상자 명패로 변경
- 학교·학년은 보조 정보, 학생 이름은 큰 글자로 강조
- 금상·은상·동상·합격·전국대회 진출마다 색상과 메달 디자인 차등 적용
- 모바일에서도 수상자 한 명씩 큰 명패로 표시


v12 수상자 텍스트 정렬 보정
- 학교명과 학생 이름 모두 완전 중앙 정렬
- 학생명 크기를 약간 줄여 학교명과의 비율 정돈
- 수상자 명패 폭을 통일하여 화면 중심 정렬 강화


v13 수상자 명패 글자 간격 개선
- 지역·학년 / 학교명 / 학생 이름을 각각 별도 줄로 분리
- 학교 약칭을 초등학교·중학교·고등학교 전체 명칭으로 확장
- 학교명은 '상 명 초 등 학 교'처럼 간격을 넓혀 표시
- 학생명은 '백　＊　우'처럼 넓은 간격으로 표시
